# Cash Accounting Information System

## 📌 Project Overview

This project focuses on analyzing and designing a Cash Accounting Information System to support cash receipt, cash payment, voucher management, and financial reporting activities.

The system aims to improve operational efficiency, reduce manual processing, and enhance accounting data management.

## 📊 Functional Modules

| Module | Description |
|---|---|
| System Management | Manage user accounts, permissions, and system configurations |
| Category Management | Manage accounting categories, accounts, partners, and reference data |
| Opening Balance Management | Initialize beginning balances for accounting periods |
| Transaction Management | Manage cash receipts, cash payments, and accounting vouchers |
| Book Management | Manage accounting books and transaction records |
| Reporting Management | Generate accounting reports and financial summaries |
